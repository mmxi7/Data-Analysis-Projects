# 🏀 NBA 선수 플레이스타일 분석 및 영입 후보 추천

## 1. 프로젝트 주제

**NBA 선수의 경기 데이터를 기반으로 플레이스타일을 분석하고, 팀의 로스터 구성에 필요한 역할을 파악하여 적합한 영입 후보 선수를 추천한다.**

### 프로젝트 흐름

```text
선수 경기 데이터
        ↓
선수 플레이스타일 분석
        ↓
유사한 특성의 선수 유형화
        ↓
팀별 선수 구성 분석
        ↓
팀에 부족한 플레이 특성 파악
        ↓
해당 특성을 보완할 선수 탐색
        ↓
영입 후보 추천
```

<br>

## 2. 문제 정의

현대 농구에서는 한 선수가 여러 역할을 수행하면서 전통적인 `PG / SG / SF / PF / C`만으로 선수의 실제 플레이 특성을 설명하기 어려운 경우가 있다.

따라서 선수의 등록 포지션만을 기준으로 선수를 평가하기보다 **실제 경기 데이터를 이용해 선수의 플레이 특성을 파악하고**, 이를 팀 구성 및 선수 영입 의사결정에 활용하고자 한다.

### 핵심 문제

> **현재 팀의 선수 구성에서 부족한 플레이 특성은 무엇이며, 이를 보완할 수 있는 선수는 누구인가?**

<br>

## 3. 프로젝트 목적

1. NBA 선수들의 경기 데이터를 이용하여 선수별 플레이 특성을 분석한다.
2. 비슷한 플레이 특성을 가진 선수들을 데이터 기반으로 유형화한다.
3. 각 팀이 어떤 유형의 선수들로 구성되어 있는지 분석한다.
4. 특정 팀에서 상대적으로 부족한 플레이 특성을 파악한다.
5. 해당 특성을 보완할 수 있는 선수를 찾아 **영입 후보를 추천한다.**

### 최종 목표

단순히 선수의 유형을 분류하는 것에서 끝나지 않고,

```text
현재 팀 분석
        ↓
부족한 플레이 특성 파악
        ↓
해당 특성이 강한 선수 탐색
        ↓
영입 후보 선정
        ↓
추천 근거 제시
```

까지 진행하는 것을 목표로 한다.

<br>

## 4. 분석 대상

- **대상:** NBA 선수
- **기간:** 한 시즌을 기준으로 분석
- **분석 단위:** 선수 1명 × 시즌
- **제외 기준:** 출전 경기 또는 평균 출전 시간이 지나치게 적은 선수

<br>

## 5. 필요 데이터

### 선수 기본 정보

| 변수 | 설명 |
|---|---|
| `Player` | 선수명 |
| `Team` | 소속팀 |
| `Position` | 등록 포지션 |
| `Age` | 나이 |
| `GP` | 출전 경기 수 |
| `MPG` | 평균 출전 시간 |

### 경기 스탯

| 영역 | 변수 |
|---|---|
| 득점 | `PTS`, `FGA`, `FGM` |
| 외곽 | `3PA`, `3PM`, `3P%` |
| 자유투 | `FTA`, `FT%` |
| 플레이메이킹 | `AST`, `TOV` |
| 리바운드 | `OREB`, `DREB`, `REB` |
| 수비 | `STL`, `BLK` |
| 효율 | `FG%`, `eFG%`, `TS%` |
| 공격 비중 | `USG%` |

필요에 따라 일반 박스스코어뿐만 아니라 Advanced Stats를 추가로 활용한다.

| **Q3** | 경기 데이터만으로 비슷한 플레이스타일의 선수들이 자연스럽게 묶이는가? |
| **Q4** | 각 선수 유형은 어떤 경기 특성을 가지고 있는가? |

| **Q8** | 후보 선수 중 현재 팀의 선수 구성과 가장 잘 맞는 선수는 누구인가? |

## 7. 분석 방법

### 7-1. 데이터 수집 및 전처리

- 선수별 시즌 경기 데이터 수집
- 결측치 및 이상치 확인
- 이적 선수 데이터 처리
- 출전 시간이 지나치게 적은 선수 제외
- 분석에 필요한 파생변수 생성
- 스케일링

단순 누적 기록은 출전 시간의 영향을 크게 받기 때문에 `Per Game`, `Per 36 Minutes`, 비율 지표 등의 활용을 검토한다.

```text
원본 데이터
    ↓
결측치 / 이상치 처리
    ↓
분석 대상 선수 선정
    ↓
파생변수 생성
    ↓
스케일링
```

<br>

### 7-2. 탐색적 데이터 분석 (EDA)

선수들의 경기 데이터 구조와 주요 특징을 파악한다.

- 스탯별 분포 확인
- 변수 간 상관관계 분석
- 포지션별 경기 특성 비교
- 팀별 경기 특성 비교
- 주요 선수 간 스탯 비교

포지션은 예측 대상이 아닌 **선수 유형을 해석하기 위한 참고 정보**로 활용한다.

<br>

### 7-3. 선수 플레이스타일 유형화

비슷한 경기 특성을 가진 선수들을 찾기 위해 비지도학습을 활용한다.

**사용 방법**

- `PCA`
- `K-Means Clustering`
- `Hierarchical Clustering`

먼저 경기 데이터를 이용하여 군집을 생성한 후, 각 군집에서 두드러지는 스탯을 분석하여 플레이스타일을 해석한다.

예시:

```text
Cluster 1 → 플레이메이킹 중심
Cluster 2 → 득점 중심
Cluster 3 → 외곽 공격 중심
Cluster 4 → 수비 / 리바운드 중심
Cluster 5 → 골밑 공격 중심
Cluster 6 → 올라운드형
```

※ 위 유형은 사전에 정하는 것이 아니라 **실제 군집 분석 결과에 따라 해석한다.**

<br>

### 7-4. 팀별 선수 구성 분석

각 팀이 어떤 플레이스타일의 선수들로 구성되어 있는지 분석한다.

```text
A팀 선수 구성

득점형          █████
플레이메이킹형  ███
외곽형          ████
수비/리바운드형 █
골밑형          ██
```

이를 통해 특정 플레이 특성을 가진 선수의 비중이 상대적으로 낮거나 높은 팀을 파악한다.

단, 특정 유형의 선수가 적다는 이유만으로 팀의 약점이라고 판단하지 않고 **실제 팀 성과 지표와 함께 비교하여 해석한다.**

<br>

### 7-5. 팀에 필요한 플레이 특성 분석

팀별 선수 구성과 실제 경기 성과를 함께 분석하여 보완이 필요한 플레이 특성을 찾는다.

예시:

```text
현재 팀 분석
    ↓
리바운드 지표 하위권
수비 지표 하위권
    ↓
현재 로스터의 선수 유형 확인
    ↓
수비 / 리바운드 특성을 가진 선수 부족 여부 분석
```

<br>

### 7-6. 영입 후보 탐색

팀에 필요한 플레이 특성을 기준으로 다른 선수들을 비교한다.

예시:

```text
팀에 필요한 특성

REB  ↑
DREB ↑
BLK  ↑
수비 관련 지표 ↑

        ↓

리그 전체 선수 탐색

        ↓

영입 후보 선정
```

<br>

### 7-7. 유사도 기반 선수 추천

팀에서 필요로 하는 선수의 특성과 리그 선수들의 특성을 비교하여 적합한 후보를 찾는다.

활용 가능한 방법:

- `Cosine Similarity`
- `Euclidean Distance`

```text
필요 선수 프로필
        ↓
리그 선수들과 유사도 계산
        ↓
후보 선수 Ranking
        ↓
추천 근거 분석
```

<br>

## 8. 추가 분석

시간적 여유가 있을 경우 현실적인 영입 조건을 추가한다.

### 추가 변수

- 선수 나이
- 연봉
- 계약 기간
- FA 여부

```text
플레이스타일 적합도
        +
나이
        +
연봉
        +
계약 상황
        ↓
최종 영입 후보 추천
```

예를 들어 가장 유사한 선수의 연봉이 지나치게 높은 경우, 유사도는 조금 낮지만 비용 대비 효율이 좋은 선수를 대안으로 제시할 수 있다.

<br>

## 9. 머신러닝 활용

본 프로젝트에서는 지도학습을 통한 예측보다 **선수의 특성을 발견하고 유사한 선수를 찾는 것**에 초점을 둔다.

| 방법 | 활용 목적 |
|---|---|
| **PCA** | 주요 플레이 특성 파악 및 차원 축소 |
| **Clustering** | 비슷한 플레이스타일을 가진 선수 유형화 |
| **Similarity** | 필요한 특성과 유사한 영입 후보 탐색 |

```text
PCA
 ↓
선수 데이터의 주요 특성 파악
 ↓
Clustering
 ↓
선수 플레이스타일 유형화
 ↓
팀 구성 분석
 ↓
Similarity
 ↓
영입 후보 추천
```

<br>

## 10. 예상 결과

최종적으로 특정 팀을 선택했을 때 다음과 같은 결과를 제시하는 것을 목표로 한다.

```text
분석 팀 : A Team

[현재 로스터 특성]

득점          82
플레이메이킹  76
외곽          85
리바운드      48
수비          51

→ 리바운드 / 수비 특성이 상대적으로 부족

[영입 추천 후보]

1. Player A
   적합도 : 91%

2. Player B
   적합도 : 87%

3. Player C
   적합도 : 83%
```

각 후보 선수에 대해서는 스탯 비교 및 시각화를 통해 **추천 이유를 함께 제시한다.**

## 12. 기대 효과

- 경기 데이터를 기반으로 선수의 실제 플레이 특성을 파악할 수 있다.
- 전통적인 포지션 구분을 넘어 선수의 플레이스타일을 데이터 기반으로 분석할 수 있다.
- 팀별 로스터 구성의 특징을 비교할 수 있다.
- 팀에 필요한 플레이 특성을 파악하고 이에 적합한 선수를 탐색할 수 있다.
- 분석 결과를 실제 선수 영입 의사결정과 연결할 수 있다.
